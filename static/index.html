How to use Syncdesk

Start with a fictional integration ticket.

  1. Describe the issue

    Enter the service, what you were trying to do, and the exact error if you have it. Then select Analyze issue.

    Stripe webhook setup: the first test event failed with HTTP 302.

  2. Review the diagnosis

    Review ready means a source matched. Check the steps against the passage in Evidence.

    Needs details means the copilot needs a follow-up, such as the exact error text or status code.

  3. Hand off a case if needed

    When you see Human review, select Queue handoff. Open Handoffs to review and copy the packet. The packet is saved in this browser for you to share manually.

Local LLM generates a cited diagnosis when Ollama and the model are available. Rules mode shows the reviewed playbook if the model is unavailable.

To cover another service, open Knowledge base → Add playbook. Add a reviewed source, the exact error or phrase, and the steps to take.
